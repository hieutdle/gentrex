METHODS AND LIMITATIONS:

{% if kind in ("panel", "single_gene") %}

Genomic DNA is enriched for the coding exons and flanking intronic sequence of the genes of this test and sequenced on a next-generation sequencing platform. Reads are aligned to the GRCh37 reference genome, and copy number variants are called from read depth. Variants are classified with the ACMG standards. {{ hgvs_example or "" }}

{% elif kind == "array" %}

Patient DNA and DNA from a sex-matched reference are labeled and hybridized to an array with copy number and SNP probes. Positions are given on the GRCh37 reference genome, and results are written in ISCN. The array does not detect balanced rearrangements, sequence variants or low-level mosaicism.

{% elif kind == "repeat" %}

The repeat-primed PCR assay screens for an expanded allele, and the fragment-length assay sizes normal alleles accurately up to about 40 repeats. Neither assay detects other kinds of variants in the gene. {{ hgvs_example or "" }}

{% else %}

Methylation-specific MLPA measures copy number and methylation at the Prader-Willi/Angelman syndrome region with a commercial probe kit. It does not tell uniparental disomy from an imprinting defect, which microsatellite analysis of chromosome 15 can. {{ hgvs_example or "" }}
